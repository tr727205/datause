WWW (World Wide Web)

1. What is WWW?

WWW (World Wide Web) is a collection of interconnected web pages and websites that can be accessed through the internet using a web browser.

It allows users to access information, images, videos, documents, and other content online.

Example: www.google.com, www.wikipedia.org.

2. Important Terms Used in WWW

1. Website: A collection of related web pages available under one domain name.

2. Web Page: A single document or page available on the internet.

3. Home Page: The main or first page of a website.

4. Web Browser: Software used to open and access websites. Example: Chrome, Firefox.

5. URL (Uniform Resource Locator): The address of a website or web page.

6. HTTP (Hypertext Transfer Protocol): A protocol used to transfer web data.

7. HTTPS (Hypertext Transfer Protocol Secure): A secure version of HTTP.

8. HTML (Hypertext Markup Language): A language used to create and structure web pages.

9. Hyperlink: A clickable link that takes users to another page or website.

10. Web Server: A computer or system that stores and delivers website content.

11. Domain Name: The human-readable name of a website. Example: google.com.

12. DNS (Domain Name System): Converts domain names into IP addresses.

13. IP Address: A unique network address used to identify a device.

14. HTTP Request: A message sent by a browser to request information from a web server.

15. HTTP Response: The message sent back by the web server to the browser.
