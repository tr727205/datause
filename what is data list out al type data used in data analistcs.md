Data and Types of Data Used in Data Analytics

1. What is Data?

Data is a collection of facts, figures, numbers, and information that can be used for analysis and decision-making.

In simple words, data is raw information collected from different sources.

Examples: Names, ages, marks, prices, dates, images, and videos.

2. Types of Data Used in Data Analytics

There are two main categories of data:

A. Qualitative Data 

Qualitative data describes qualities or characteristics. It is generally expressed in words or categories.

Types:

Nominal Data: Data without any specific order. Example: Gender, City, Colors.

Ordinal Data: Data arranged in a particular order. Example: Low, Medium, High.

B. Quantitative Data 

Quantitative data represents information in numbers that can be counted or measured.

Types:

Discrete Data: Data that can be counted in whole numbers. Example: Number of students, Cars, Books.

Continuous Data: Data that can be measured and can have decimal values. Example: Height, Weight, Temperature.

3. Other Common Data Types in Data Analytics

Numerical Data: Numbers such as age, salary, and marks.

Categorical Data: Categories such as gender, city, and color.

Text Data: Words, sentences, and messages.

Date and Time Data: Dates, years, and time.

Boolean Data: Two possible values: True or False.

Image Data: Photos and pictures.

Audio Data: Voice recordings and music.

Video Data: Video recordings and clips.

5. Conclusion

Data is the foundation of data analytics. It helps us understand information, identify patterns, solve problems, and make better decisions. Different types of data are used according to the requirements of analysis.
