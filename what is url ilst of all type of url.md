    1. Introduction
URL stands for Uniform Resource Locator.

A URL is the address of a website, webpage, image, video, or file on the internet.

Examples:

https://www.google.com

https://www.youtube.com

https://www.wikipedia.org

2. Definition of URL    

A URL is an address used to locate and access a specific resource on the internet.


3. Types of URL
    
URLs are classified into different types based on their structure, protocols, purposes, and accessibility.

A. Structure-Based URL Types

 
1. Absolute URL 

An absolute URL contains the complete web address, including the protocol and domain name.

Example: https://example.com/about  

2. Relative URL

A relative URL contains only the path to a webpage or resource.

Example: about.html

3. Root-Relative URL

A root-relative URL starts from the root directory of a website.

Example: /about

4. Protocol-Relative URL

A protocol-relative URL does not specify HTTP or HTTPS.

Example: //example.com/page
