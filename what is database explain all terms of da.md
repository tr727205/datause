Database and Its Important Terms

1. What is a Database?

A Database is an organized collection of data that is stored electronically and can be easily accessed, managed, updated, and retrieved.

In simple words, a database is used to store and manage information in an organized way.

Examples: Student records, employee details, bank accounts, customer information.

2. Important Terms of Database

1. Data: Raw facts and information. Example: Name, age, marks.

2. Database: An organized collection of related data.

3. DBMS (Database Management System): Software used to create, store, manage, and access databases. Example: MySQL, Oracle.

4. Table: A structure used to store data in rows and columns.

5. Row (Record): A horizontal entry in a table that contains information about one item or person.

6. Column (Field): A vertical section of a table that represents a particular type of information.

7. Primary Key: A field that uniquely identifies each record in a table.

8. Foreign Key: A field that connects one table with another table.

9. SQL (Structured Query Language): A language used to manage and communicate with databases.

10. Query: A request used to retrieve or modify data in a database.

11. Schema: The overall structure or design of a database.

12. Backup: A copy of database information kept for recovery.

3. Types of Databases

Relational Database: Stores data in tables. Example: MySQL, Oracle.

NoSQL Database: Stores data in flexible formats. Example: MongoDB.

Hierarchical Database: Organizes data in a tree-like structure.

Network Database: Organizes data using interconnected records.

Cloud Database: Stores and manages data on cloud servers.

4. Uses of Database

Storing student records.

Managing bank accounts.

Storing customer information.

Managing employee details.

Maintaining online shopping records.

5. Advantages of Database

Stores large amounts of data.

Makes data easy to access.

Reduces data duplication.

Improves data security.

Makes data management easier.

6. Conclusion

A database is an important part of computer systems. It helps store, organize, manage, and retrieve information easily. Databases are widely used in schools, banks, hospitals, businesses, and websites.
