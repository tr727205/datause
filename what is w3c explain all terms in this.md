W3C (World Wide Web Consortium)

1. What is W3C?


W3C (World Wide Web Consortium) is an international organization that develops standards and guidelines for the World Wide Web.

It helps make websites accessible, secure, user-friendly, and compatible with different browsers and devices.

Founder: Tim Berners-Lee

Established: 1994

2. Important Terms Related to W3C

1. HTML (HyperText Markup Language): Used to create and structure web pages.

2. CSS (Cascading Style Sheets): Used to design and style web pages.

3. XML (Extensible Markup Language): Used to store and organize data.

4. DOM (Document Object Model): Represents the structure of a web page so programs can access and modify it.

5. SVG (Scalable Vector Graphics): Used to create graphics and images on websites.

6. Web Accessibility (WAI): Helps people with disabilities access websites.

7. Web Standards: Rules and guidelines that help websites work properly across different browsers.

8. WCAG (Web Content Accessibility Guidelines): Guidelines for making websites accessible to everyone.

9. Semantic HTML: Uses meaningful HTML elements to describe web page content.

10. Web Compatibility: Ensures websites work properly on different browsers and devices.

3. Main Functions of W3C

Develops web standards.

Improves website accessibility.

Promotes web security and compatibility.

Supports web development technologies.

Helps improve the quality of websites.
